# Unicorn-Companies-Analysis

# 🦄 Unicorn Companies Dataset

## 📌 Overview

The **Unicorn Companies Dataset** contains information about privately held companies that have achieved **unicorn status**, meaning they have reached a valuation of **$1 billion or more**.

This dataset can be used for **Exploratory Data Analysis (EDA), data visualization, business intelligence, investment analysis, and machine learning projects**.

The dataset includes information about each company's valuation, industry, location, founding year, funding, and investors.

---

## 📂 Dataset Information

| Property | Details |
|---|---|
| Dataset Name | Unicorn Companies |
| Number of Records | 1,074 |
| Number of Features | 10 |
| File Format | Excel (.xlsx) |
| Main Use | Data Analysis & Visualization |

---

## 📊 Features / Columns

| Column | Description |
|---|---|
| **Company** | Name of the unicorn company |
| **Valuation** | Estimated company valuation |
| **Date Joined** | Date on which the company became a unicorn |
| **Industry** | Industry or business sector of the company |
| **City** | City where the company is headquartered |
| **Country** | Country where the company is headquartered |
| **Continent** | Continent where the company is located |
| **Year Founded** | Year in which the company was founded |
| **Funding** | Total funding raised by the company |
| **Select Investors** | Major investors associated with the company |

## 🎯 Objectives

The dataset can be analyzed to:

- Identify the most valuable unicorn companies.
- Analyze unicorn companies by **industry**.
- Compare unicorn companies across **countries and continents**.
- Study the relationship between **funding and valuation**.
- Identify industries producing the largest number of unicorns.
- Analyze the growth of unicorn companies over the years.
- Identify major investors involved in unicorn companies.
- Understand the geographical distribution of unicorn companies.
